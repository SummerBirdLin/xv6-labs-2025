1. First 10 pages (va 0x0 ~ 0x9000):
- va 0x0 (perm 0x5B = PTE_A|PTE_U|PTE_X|PTE_R|PTE_V): User text segment (page 1), containing executable instructions and read-only data.
- va 0x1000 (perm 0x5B = PTE_A|PTE_U|PTE_X|PTE_R|PTE_V): User text segment (page 2), containing executable instructions and read-only data.
- va 0x2000 (perm 0x17 = PTE_U|PTE_W|PTE_R|PTE_V): User data/BSS segment, containing readable and writable global/static variables.
- va 0x3000 (perm 0x07 = PTE_W|PTE_R|PTE_V): Stack guard page, mapped without PTE_U so user-mode stack overflow triggers a page fault.
- va 0x4000 (perm 0xD7 = PTE_D|PTE_A|PTE_U|PTE_W|PTE_R|PTE_V): User stack page, readable and writable by user mode (accessed and dirty).
- va 0x5000 ~ 0x9000 (perm 0x0): Unmapped pages above the initial process size (heap not yet allocated).

2. Last 10 pages (va 0x3FFFFF6000 ~ 0x3FFFFFF000):
- va 0x3FFFFF6000 ~ 0x3FFFFFC000 (perm 0x0): Unmapped virtual address space.
- va 0x3FFFFFD000 (USYSCALL, perm 0x13/0x53 = PTE_U|PTE_R|PTE_V): Read-only user-accessible page shared with the kernel storing struct usyscall (process PID). (Initially 0x0 before implementing ugetpid).
- va 0x3FFFFFE000 (TRAPFRAME, perm 0xC7 = PTE_D|PTE_A|PTE_W|PTE_R|PTE_V): Trapframe page saving user registers across traps; accessible only in supervisor mode (no PTE_U).
- va 0x3FFFFFF000 (TRAMPOLINE, perm 0x4B = PTE_A|PTE_X|PTE_R|PTE_V): Trampoline code page (uservec/userret) for transitioning between user and supervisor mode; supervisor-only (no PTE_U).
